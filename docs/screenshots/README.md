# 界面截图

审核要求 README 里有 **2–4 张截图**说明插件怎么用。把图按下面的**文件名**放进本目录即可（引用已经写在仓库根 README 的「三、界面预览」一节里，放进来就会显示）。

| 文件名 | 截什么 | 要点 |
|---|---|---|
| `1-range.png` | 向导第 1 步 · 选记录范围 | 能看到「预计产出 N 份」这类事实卡，证明有取数能力 |
| `2-template.png` | 向导第 2 步 · 选模板 | 能看到模板卡片 / 骨架库，证明有可用的模板来源 |
| `3-preview.png` | 向导第 3 步 · 打印预览 | **最关键**：一张真实的单据/台账渲染效果 |
| `4-editor.png` | 模板编辑器 | 画布 + 左侧字段面板 + 右侧属性面板，证明可编辑 |

## 截图注意

- **用真实数据**（可以建一张测试表），空白表的截图说服力很低；
- 一张图只讲一件事，别拼图；
- 建议 **宽度 ≥ 1200px**，飞书插件是窄侧边栏，截完整窗口比只截局部更能说明场景；
- 如果是给审核员看的「功能演示」，可以把第 3、4 步录成 **10–30 秒的 GIF/MP4**（#6 那栏允许附演示）。
